What happens the first time you open it

  1. Windows will warn you. "Windows protected your PC" appears because the app is not code-signed — a certificate costs a few hundred dollars a year. Click More info, then Run anyway.
  2. It sets itself up, once. About a minute, while it builds a private Python environment. It does not touch anything else installed on your machine, and it does not do this again.
  3. You need Python 3.10 or newer. If it is missing the app says so and points you at python.org — tick "Add Python to PATH" when installing.

What is different from the website

Accounts and payment stay here. Signing in with Google and upgrading both need a fixed public address, which an app running on your own computer does not have — so the app links back to this site for those, and picks up the account you signed into. Everything else runs locally.
