What answers you

RandomGenerals AI runs on Ollama, a real language model executing entirely on this machine — no model detected yet. There is no cloud API call in the loop: nothing you type leaves this computer.

What it can get wrong

Like any language model, it can state things confidently and be wrong, especially about recent events, niche facts, or anything it was never trained on. Treat answers as a starting point, not ground truth — verify anything that matters.

The other experiment in this repo

brain/ holds a second, much smaller model built from scratch in plain NumPy — no PyTorch, no pretrained weights, every matrix and gradient hand-written. It's not wired into this chat (a few hundred thousand parameters can't hold a conversation), but the code trains and runs on its own: python brain/train.py.
