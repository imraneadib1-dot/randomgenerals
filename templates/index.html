    What answers you
    
            
    
              pip 1.0 is our own language model, owned by
              Imrane Adib and served by its own engine on hardware we run —
              no model detected yet. When
              the engine cannot answer, a backup model does, and every
              reply says which one it came from.
            
    
          
    

          
    
            
    What it can get wrong
    
            
    
              Like any language model, it can state things confidently and
              be wrong, especially about recent events, niche facts, or
              anything it was never trained on. Treat answers as a
              starting point, not ground truth — verify anything that
              matters.
            
    
          
    

          
    
            
    The small model that reads first
    
            
    
              Before any big model sees your message, a tiny network in
              brain/ — built from scratch in plain NumPy,
              every gradient written by hand — reads it and decides
              which bay it belongs to. A coding question typed into Chat
              gets the coding prompt because of it. It runs in a fifth
              of a millisecond on the server's own CPU and is right 95%
              of the time when it says it is sure.
