FAQ

Questions worth asking

Where does the AI actually run?

Two places, and each reply says which. Where a model is running on the host machine, through Ollama, your message stays on it. Otherwise it goes to Groq, which runs the same kind of open-weight model on faster hardware — on this hosted site that is usually what answers, because the server has no GPU. Image generation always sends the description to Pollinations. Run it yourself and the local path is the only one that is used.

How good is it compared to ChatGPT or Claude?

Honestly: not as good, and it's worth saying plainly. Those run models hundreds of times larger on datacentre hardware. This runs 7-billion-parameter models on a single GPU. It's genuinely useful for everyday questions, coding help, and drafting — but it will be less accurate on hard reasoning, and it can be wrong with confidence.

What are credits?

A usage meter, charged by how much the model actually generates rather than a flat fee per message — so short answers cost little. They refill automatically on a timer; you never lose access permanently.

Is the code runner safe?

It runs in a locked-down subprocess with a hard timeout, a memory cap, no access to installed packages, and a throwaway working directory — and it's limited to signed-in accounts. It is not a full container, so it isn't network-isolated. That limitation is documented rather than glossed over.

Do I need an account?

No — you can start chatting immediately as a guest, and your conversations stay private to your browser session. Making an account keeps your history and credits across devices, and signing up carries your guest conversations over with you.
